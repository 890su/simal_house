# Двор и Дом

Три русскоязычных прототипа лендингов. Название рабочее. Страницы можно открыть локально или раздавать из папки `dist` через статический сервер. Сборка и зависимости для запуска не нужны.

- `dist/index.html` — домикомплект для своего участка. Содержит три модели, схемы, выбор комплектации и форму запроса сметы.
- `dist/property.html` — предварительное предложение дома с землёй в Аджарии. Адрес, цена и дата показов зависят от фактической сделки с землёй.
- `dist/hospitality.html` — гостевые домики для бизнеса. Содержит сравнение первой единицы и партии, вопросы по участку, сроку и оснащению.

Демо-формы готовят текстовый файл без отправки на сервер и сбора контактов. Перед запуском подключаются канал приёма заявок и обработка персональных данных, согласовываются бренд и грузинская версия. Для объекта с землёй потребуются реальная фотография, кадастр, площадь участка, цена и условия показа. Для карточек моделей используются материалы производителя в целях обсуждения макета. Перед открытой публикацией нужно подтвердить право на их использование.
