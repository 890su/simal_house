# ეზო და სახლი · Двор и Дом

Три лендинга на трёх языках. Грузинский — основной (`dist/`), русский и английский — в `dist/ru/` и `dist/en/`.

- `index.html` — домокомплект на свой участок: модели, что входит, цена по строкам, доставка, сезон, заявка.
- `hospitality.html` — гостевые домики для отелей, глэмпингов и виноделен: «Наина», партия, что делаем, окупаемость.
- `property.html` — готовый дом «Наина 6 × 6» с участком в Аджарии (проект, сбор контактов до показа).

## Как менять

| Что | Где |
|---|---|
| Телефон, WhatsApp, Telegram, адрес приёма заявок, индексация | `site.config.mjs` → `site` |
| Цена «от», процент сборки, срок изготовления | `site.config.mjs` → `site` |
| Цена конкретной модели, наличие на складе | `site.config.mjs` → `models[].price`, `models[].stock` |
| Тексты | `copy.mjs` (ka / ru / en) |
| Разметка страниц | `build.mjs` |
| Стили и поведение | `dist/styles.css`, `dist/main.js` |

После правок: `node build.mjs` — заново создаёт 9 HTML-страниц.

## Заявки

Форма работает в трёх режимах, выбор автоматический:

1. `formEndpoint` заполнен — POST JSON (страница, язык, поля формы, UTM, gclid/fbclid).
2. Пусто, но заполнен `whatsapp` — открывается WhatsApp с готовым текстом заявки.
3. Оба пусты — демо: посетитель видит, что заявка не отправлена.

События для аналитики уходят в `window.dataLayer`: `view_model`, `view_price_scope`, `quote_start`, `quote_submit`, `lead`, `contact_whatsapp`, `catalog_request`, `intent`.

## Перед запуском

- [ ] Номера и `formEndpoint` в `site.config.mjs`, `baseUrl` и `index: true`.
- [ ] Вычитка грузинского текста носителем.
- [ ] Цены моделей после экспортного КП фабрики.
- [ ] Реальные фото после первой сборки вместо визуализаций.
- [ ] Политика обработки персональных данных (ссылка рядом с формой).

## Изображения и шрифты

Сцены домов — сгенерированные визуализации заводских моделей Борисовского ДОКа, на сайте подписаны «Визуализация». Планировки рисуются в SVG из данных `models` (площади по каталогу 2025, страница в поле `page`).

Шрифт FiraGO (SIL OFL, `dist/assets/firago-OFL.txt`), подмножество латиница + кириллица + грузинский. Старые шрифты и растровые планировки перенесены в `_unused-assets/`.

Дизайн-система описана в `DESIGN.md`.
